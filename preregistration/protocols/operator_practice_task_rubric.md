# Operator non-study practice-task rubric

Status: `PENDING_REAL_ASSESSMENT`

Use a practice scenario that is not one of the 36 confirmatory scenarios. The
operator uses only the workflow for which authorisation is sought.

The task passes only when all of the following are documented:

1. all common deliverables in `baseline_SOPs.md` are present;
2. no prohibited workflow feature or cross-workflow output is used;
3. every input need has a recorded disposition and source link where required;
4. geometry, parameter table, budget, regulatory checklist, and process log can
   be read by the frozen evaluator;
5. stopping caps and first-schema-valid-response rules are followed; and
6. no unresolved critical data-integrity or provenance error remains.

Record the practice-task ID, workflow, assessor code, pass/fail result, failure
reasons, artifact hash, and assessment date. A failed operator may retrain and
repeat a new non-study task; retain all attempts.
