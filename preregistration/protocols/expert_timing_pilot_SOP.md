# Non-study expert timing pilot SOP

Status: `PENDING_EXECUTION`

This pilot is a feasibility check and is not part of the approved expert sample.
Do not recruit or consent approved reviewers using pilot data.

## Pilot sample

Use at least three adults who satisfy the task-language and device requirements
but are not enrolled, recruited, or identifiable as participants in Experiment 3.
Record only a pilot code (`PILOT01`, etc.), language, device class, and timing.
Do not record expert ratings as study data.

## Task

Run the exact intended online interface with a representative nine-scenario
allocation, 27 anonymised outputs, five seven-point ratings per output, the
forced-choice preference items, and the post-task blinding checks. Use the
candidate approved wording; any wording change is recorded and does not count
as evidence for the ethics-version gate.

## Timing and decision rule

The desk burden check is intentionally conservative: 27 outputs times five
ratings equals 135 ordinal responses. The full 30--60 minute window allows only
66.7--133.3 seconds per output, or 13.3--26.7 seconds per rating, before reading,
preferences, transitions, and blinding checks. Arithmetic alone therefore
cannot establish feasibility; the real full-interface pilot is mandatory.

Start the timer when the scenario package opens and stop after submission of all
required items. Record active minutes, elapsed minutes, pauses over two minutes,
technical interruptions, missing items, and whether the tester completed all
items without assistance.

The pilot passes only if every tester completes every required item, no tester
requires substantive assistance, and every elapsed time is between 30 and 60
minutes. Any failure pauses expert recruitment and requires task/ethics review;
no timing result is silently discarded.
